# Lab010 PATRON DECORATOR 
Practica del patron decorator de un sistema de pedidos de cafe con distintos complementos 

## Estructura:
- Bebida: interface que define descrpcion y precio
- DecoradorBebida: clase abstracta 
- Componentes: TostadoNegro, Batido, Descafeinado, Expreso
- Complementos (decoradores): Conleche, ConMoca, Consoya, Concrema
- Main: clase que ejecuta todos los pedidos
